# SmartPortfolio Admin Guide

Open `/admin` and use the sidebar to manage the portfolio. Profile and Website Settings control identity, contact, logo, footer, and CV label. Content modules manage experience, education, skills, certifications, projects, services, achievements, testimonials, and clients. Active and Order fields control public visibility and sequence.

Posts support draft, published, and archived states, dates, excerpts, sanitized rich HTML, and SEO copy. Pages publish at `/page/<slug>`; custom sections create reusable homepage blocks. Media accepts validated JPG, PNG, WEBP, and PDF files. Inbox supports unread/read and deletion. Menus, sections, theme, layout, and SEO control site structure and presentation.

Use lowercase hyphenated slugs. Preview after navigation/design changes. Reserve Super Admin accounts for trusted operators and rotate passwords securely.
