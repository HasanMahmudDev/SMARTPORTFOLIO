# SmartPortfolio Commercial Setup

For each buyer, replace demo identity/content, configure menus and sections, select and customize a preset, set domain/SEO/analytics, upload branding and CV, then complete the Hostinger acceptance tests. Give every customer a unique database, `.env`, administrator password, JWT secrets, domain, SSL certificate, and upload directory. Never reuse secrets.

The `adminHMD` repository informed the administration shell's layout language. Its README says personal/commercial use requires proper licensing; confirm applicable terms for your distribution channel. SmartPortfolio does not bundle that repository's source or vendor assets.
