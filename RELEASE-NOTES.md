# SmartPortfolio v1.0.0 Release Notes

Initial commercial release: responsive public portfolio and administration panel, comprehensive MySQL schema, secure administrator setup, reusable REST CRUD, publishing workflow, validated uploads, sanitized HTML, contact inbox, eight editable presets, layout builder, custom pages/sections, SEO routes, production SPA routing, and Hostinger documentation.

Requires Node.js 20+ and MySQL 8-compatible hosting. Run `npm run setup:admin` with `ADMIN_PASSWORD` supplied through the environment; the release contains no administrator password, password hash, JWT secret, or database credential.
